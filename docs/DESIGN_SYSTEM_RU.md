# Дизайн-система OSINT Panel 4.4

## Цель
Все страницы должны ощущаться как одна аналитическая рабочая станция, а не набор независимых мини-сайтов. Базовый стиль: Dark Intelligence Workstation — тёмно-синий фон, сдержанный голубой акцент, компактная навигация, читаемые таблицы и моноширинное отображение технических значений.

## Общие правила
- Основной фон: `#080D14`; панели: `#101925`; карточки: `#111D2A`.
- Акцент: `#59B8F5`; основной текст: `#E6EDF5`; вторичный текст: `#91A2B6`.
- Основной шрифт: системный sans-serif (Inter при наличии); IP, хеши, домены и консольный вывод — моноширинный.
- Радиусы карточек 8–12 px; одинаковые границы, фокус-кольца и состояния кнопок.
- Убраны постоянно движущиеся декоративные частицы и сканирующая полоса, чтобы не отвлекать от результатов.
- На узких экранах навигация прокручивается горизонтально, а не ломает шапку.

## Общие элементы
- Единая компактная шапка и активная навигация.
- Общие действия «Назад», «Главная» и «Рабочая область».
- Рабочая область хранит только то, что пользователь явно закрепил, локально в текущем браузере. Она не синхронизируется с сервером.
- Перед полной очисткой рабочей области показывается подтверждение.
- Все страницы используют единый набор токенов и общие стили контролов.

## Назначение страниц и визуальные акценты
| Страница | Основной визуальный паттерн |
|---|---|
| Главная | Компактный обзор инструментов, поиск и категории |
| Domain OSINT | DNS/WHOIS/SSL и поддомены в отдельных секциях |
| Username OSINT | Список платформ, статусы и фильтры |
| Photo Intelligence | Загрузка, предпросмотр и отдельные блоки OCR/QR/EXIF/AI |
| IP / RDAP | Поле IP и структурированный регистрационный вывод |
| AI Agent | Диалог, история и отдельные блоки кода/ответов |
| ANONSMS | Компактная форма, результат и статус запроса |
| Instagram | Только предусмотренные проектом функции, с явными статусами |
| GrabCam | Отдельные статусы локального сервера/туннеля и прозрачная демонстрация разрешений |
| History | Хронология, фильтры и повторный просмотр |
| Settings | Секции API, проверка подключения и локальные настройки |

## Важно для разработчиков
- Общая тема находится в `static/css/unified-workstation.css`.
- CSS-бандлы собираются в `backend/css_bundle.py`; unified stylesheet подключается после стилей конкретного инструмента, чтобы общие правила имели единый приоритет.
- Отдельные страницы Domain, Username и IP/RDAP подключают общую тему напрямую.
- Не добавлять локальные цветовые палитры или новые шрифты без обновления дизайн-системы.
- Не заменять существующие API/DOM-контракты при косметическом редизайне.
- При добавлении новых элементов использовать семантические HTML-контролы, видимые focus-состояния и `prefers-reduced-motion`.

## Проверка
После изменений проверить каждую страницу на широком и мобильном экране, активную навигацию, кнопку «Назад», открытие рабочей области, сохранение/копирование/удаление закреплённых результатов и работу основных форм. CSS-проверка сама по себе не подтверждает корректность backend или внешних инструментов.
