# Установка OSINT Panel в Kali Linux и Debian

Это руководство разделяет **обязательные зависимости панели**, **Python-пакеты инструментов** и **системные утилиты для отдельных функций**. Не устанавливайте всё подряд через `apt`: сначала выберите нужные инструменты.

## 1. Что требуется обязательно

| Компонент | Обязательно | Назначение |
|---|---:|---|
| Python 3.10+ | Да | Backend и запуск панели |
| python3-venv | Да, рекомендуется | Изолированное окружение Python |
| Git | Для клонирования/обновления через Git | Получение исходного кода |
| Flask и Flask-CORS | Да | HTTP-сервер и API; входят в `requirements.txt` |
| Интернет | Для установки и внешних OSINT-запросов | Загрузка зависимостей и работа внешних источников |

## 2. Установка базовых системных пакетов

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

Получите проект и перейдите в каталог:

```bash
git clone https://github.com/ERRORoX/OSINT.git
cd OSINT
```

Если проект уже клонирован, повторно клонировать его не нужно.

## 3. Создание виртуального окружения

Для Kali Linux это рекомендуемый способ: он не изменяет системный Python и помогает избежать ошибки PEP 668.

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

После активации окружения в начале приглашения терминала обычно появляется `(venv)`.

## 4. Запуск

```bash
python3 run.py
```

Откройте в браузере:

```text
http://127.0.0.1:5000
```

Остановка сервера: `Ctrl+C` в терминале, где запущен `run.py`.

## 5. Системные утилиты — устанавливайте по необходимости

Эти программы не являются Python-пакетами из `requirements.txt`.

| Пакет Kali/Debian | Для чего нужен | Когда устанавливать |
|---|---|---|
| `tesseract-ocr` | OCR — распознавание текста на изображениях | Если используете OCR |
| `tesseract-ocr-eng` | Английская языковая модель OCR | Для английского текста |
| `tesseract-ocr-rus` | Русская языковая модель OCR | Для русского текста |
| `libimage-exiftool-perl` | Расширенное чтение метаданных EXIF | Для EXIF-анализа |
| `php-cli` | Локальный PHP-сервер учебной страницы GrabCam | Для локального запуска GrabCam |
| `openssh-client` | SSH-клиент для поддерживаемых SSH-туннелей | Если используете Serveo/localhost.run |
| `libzbar0` (библиотека ZBar) | Системная поддержка некоторых сценариев чтения QR | Если QR-функция сообщает об отсутствии ZBar |
| `golang` | Сборка Go-инструментов | Только если собираете Subfinder/dnsx самостоятельно |

Установка распространённых утилит:

```bash
sudo apt install -y tesseract-ocr tesseract-ocr-eng tesseract-ocr-rus
sudo apt install -y libimage-exiftool-perl php-cli openssh-client
```

Для ZBar пакет нужен библиотеке pyzbar во время выполнения QR-функции. Если QR-модуль не используется, его можно не устанавливать.

**Cloudflare Tunnel (`cloudflared`)** устанавливается отдельно из официального пакета Cloudflare для вашей архитектуры. Он не входит в Python-зависимости проекта. Если используете только локальный GrabCam, устанавливать его не требуется.

## 6. Что устанавливает requirements.txt

Файл `requirements.txt` содержит Python-зависимости панели и подключённых модулей, в том числе:

- Flask, Flask-CORS — backend и API.
- Requests, BeautifulSoup — HTTP-запросы и разбор HTML.
- Pillow, pytesseract, pyzbar — обработка изображений, OCR и QR-интеграция.
- dnspython — DNS-проверки.
- Sherlock, Maigret, Social Analyzer, Blackbird — поиск публичных username-профилей.
- Holehe, h8mail — модули проверки публичных сигналов по email.
- theHarvester — сбор публичной информации о доменах.
- pandas, openpyxl, reportlab и вспомогательные библиотеки — обработка и экспорт данных.

Установка полного файла ставит зависимости сразу для нескольких модулей, даже если вы используете не каждый из них. Системные бинарники (PHP, Tesseract, ExifTool, Go и cloudflared) этим файлом не устанавливаются.

## 7. Go-инструменты

Subfinder и dnsx — отдельные Go-бинарники, а не Python-пакеты. Если вы не используете эти инструменты, Go можно не устанавливать.

Сборка выполняется по инструкциям соответствующих каталогов проекта. Не копируйте бинарники с другой архитектуры или операционной системы.

## 8. Проверка окружения

После установки выполните:

```bash
python --version
python -c "import flask, flask_cors; print('Flask OK')"
command -v php || true
command -v tesseract || true
command -v exiftool || true
command -v ssh || true
command -v cloudflared || true
```

Отсутствие необязательной утилиты не означает, что вся панель неисправна: недоступной будет только функция, которой она требуется.

## 9. Обновление и восстановление

- Для обычного обновления используйте кнопку **«↻ Обновить»** в панели, если она доступна в установленной версии.
- Не удаляйте вручную каталоги `data/`, `.env`, пользовательские настройки и виртуальное окружение, если не понимаете последствия.
- Перед ручным восстановлением сохраните резервную копию пользовательских данных и конфигурации.
- Не запускайте случайные shell-команды из непроверенных источников от имени root.

## 10. GrabCam: границы учебного режима

GrabCam в текущем учебном режиме поднимает изолированную демонстрационную страницу. Камера и геолокация запрашиваются только после отдельного действия посетителя в браузере; изображение камеры показывается локально, а координаты — на самой демонстрационной странице. Данные посетителя не отправляются и не сохраняются.

Открытие произвольного стороннего сайта (например, Instagram) не даёт локальной панели права запрашивать разрешения от имени этого сайта. Для демонстрации браузерных разрешений используется отдельная, явно обозначенная учебная страница.
