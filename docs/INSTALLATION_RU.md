# Установка OSINT Panel в Kali Linux / Debian

Это руководство объясняет, что действительно нужно для запуска панели, что устанавливается автоматически через Python, а что требуется только отдельным функциям. **Не устанавливай все дополнительные утилиты без необходимости.** Docker, Node.js и npm для обычного запуска панели не требуются.

## 1. Что нужно обязательно

| Компонент | Обязателен? | Для чего |
|---|---|---|
| Python 3.10 или новее | Да | Backend Flask и инструменты |
| `python3-venv` | Настоятельно рекомендуется | Отдельное окружение Python, чтобы не менять системный Python Kali |
| `python3-pip` | Да | Установка Python-библиотек |
| Git | Только для клонирования и Git-обновлений | Получение исходного кода |
| Интернет | Для установки и большинства внешних OSINT-запросов | Загрузка библиотек и обращения к источникам |

Базовая установка системных пакетов:

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip
```

## 2. Получение проекта

Для новой установки:

```bash
git clone https://github.com/ERRORoX/OSINT.git
cd OSINT
```

Если каталог проекта уже есть, **не клонируй его повторно** — перейди в существующий каталог:

```bash
cd /путь/к/OSINT
```

> Для установленной панели планируется штатное обновление кнопкой «↻ Обновить». Не переключай вручную ветки и не запускай параллельно второй установщик, если пользуешься встроенным обновлением.

## 3. Автоматическая установка (рекомендуется)

В корне проекта находится установщик `install.sh`. Он проверяет версию Python, при необходимости устанавливает базовые системные пакеты, создаёт или использует существующий `venv`, устанавливает `requirements.txt` и проверяет основные Python-модули.

Из корня репозитория выполни:

```bash
bash install.sh
```

После завершения запусти панель:

```bash
source venv/bin/activate
python run.py
```

Открой `http://127.0.0.1:5000`.

Дополнительные системные утилиты для OCR, EXIF, QR, GrabCam и Go можно установить отдельно:

```bash
bash install.sh --with-optional
```

Если базовые системные пакеты уже установлены и apt запускать не нужно:

```bash
bash install.sh --no-apt
```

Установщик можно запускать повторно: он использует существующий `venv` и не удаляет `.env`, `data/` или базы SQLite. Он не устанавливает Cloudflare Tunnel; для него используй официальную инструкцию Cloudflare.

## 3. Установка Python-зависимостей

В Kali используй виртуальное окружение. Это предотвращает конфликт с системным Python и ошибку `externally-managed-environment`.

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если команда активации выполнена успешно, в начале приглашения терминала обычно появится `(venv)`.

### Что делает requirements.txt

Файл устанавливает Python-пакеты, используемые панелью и подключёнными Python-инструментами:

| Группа | Пакеты из requirements.txt | Назначение |
|---|---|---|
| Backend | Flask, Flask-CORS | Локальный веб-сервер и API |
| HTTP / HTML | requests, beautifulsoup4, requests-html, httpx | HTTP-запросы и разбор страниц |
| Фото | Pillow, pytesseract, pyzbar | Изображения, OCR-обёртка и QR |
| DNS | dnspython | DNS-запросы |
| Username | sherlock-project, локальный Maigret, Social Analyzer, Blackbird и их библиотеки | Поиск публичных профилей |
| Email | holehe, h8mail и вспомогательные библиотеки | Проверка публичных сигналов по email |
| Домены | theHarvester и PyYAML | Сбор публичных сведений о доменах |
| Экспорт / данные | pandas, openpyxl, reportlab | Таблицы и отчёты |
| Прочее | colorama, rich, python-dotenv, phonenumbers и другие зависимости | Интерфейс командной строки, конфигурация и вспомогательные функции |

**Важно:** `pip install -r requirements.txt` устанавливает весь список, в том числе библиотеки инструментов, которыми ты можешь не пользоваться. Но системные программы — PHP, Tesseract, ExifTool, Go, cloudflared — этот файл не устанавливает.

## 4. Что устанавливать дополнительно

Устанавливай только то, что нужно для выбранной функции:

| Пакет Kali/Debian | Для чего нужен | Можно не устанавливать, если… |
|---|---|---|
| `tesseract-ocr` | Сам движок распознавания текста на фото | Не используешь OCR |
| `tesseract-ocr-eng` | Английские данные OCR | Не распознаёшь английский текст |
| `tesseract-ocr-rus` | Русские данные OCR | Не распознаёшь русский текст |
| `libimage-exiftool-perl` | Расширенное чтение EXIF | Не используешь соответствующий EXIF-сценарий |
| `php-cli` | Локальный PHP-сервер учебной страницы GrabCam | Не запускаешь GrabCam |
| `libzbar0` | Системная библиотека ZBar для QR через pyzbar | Не используешь QR-сканирование |
| `openssh-client` | SSH-клиент для поддерживаемого SSH-туннеля | Используешь только локальную страницу или другой способ туннеля |
| `golang-go` | Компиляция Go-инструментов | Не собираешь Subfinder/dnsx из исходников |
| `cloudflared` | Cloudflare Tunnel для внешней ссылки GrabCam | Нужен только локальный доступ или другой туннель |

### Установка OCR и EXIF

```bash
sudo apt install -y tesseract-ocr tesseract-ocr-eng tesseract-ocr-rus libimage-exiftool-perl
```

### Установка компонентов GrabCam

Для локального PHP-сервера:

```bash
sudo apt install -y php-cli
```

Для SSH-туннеля:

```bash
sudo apt install -y openssh-client
```

Cloudflare Tunnel устанавливай отдельно по официальной инструкции Cloudflare и только если действительно нужен этот тип внешней ссылки. Он не входит в `requirements.txt`.

### Установка поддержки QR

```bash
sudo apt install -y libzbar0
```

Если QR-функция не используется, этот пакет можно пропустить.

## 5. Go-инструменты: Subfinder и dnsx

Subfinder и dnsx — отдельные исполняемые программы. Они не устанавливаются командой `pip install -r requirements.txt`. Go нужен только если ты собираешь эти инструменты из исходного кода.

```bash
sudo apt install -y golang-go
```

Проверь:

```bash
go version
```

Сборка выполняется из соответствующего каталога инструмента по его README. Не скачивай бинарники для другой ОС или архитектуры.

## 6. Запуск панели

Из корневого каталога проекта, с активированным `venv`:

```bash
python run.py
```

Открой в браузере:

```text
http://127.0.0.1:5000
```

Остановить сервер можно сочетанием `Ctrl+C` в терминале. Не закрывай терминал, пока используешь панель.

## 7. Проверка установки

В активном виртуальном окружении:

```bash
python --version
python -c "import flask, flask_cors, requests; print('Основные Python-пакеты: OK')"
command -v php || true
command -v tesseract || true
command -v exiftool || true
command -v ssh || true
command -v go || true
command -v cloudflared || true
```

Отсутствие необязательной программы не означает, что вся панель сломана. Может быть недоступна только конкретная функция, которой эта программа требуется.

## 8. Обновление, резервные копии и восстановление

- Для штатного обновления используй кнопку «↻ Обновить» в панели.
- Перед заменой файлов обновляющая система должна сохранять резервную копию и проверять результат операции.
- Не удаляй вручную `data/`, `.env`, базу SQLite, пользовательские настройки или `venv/` ради «чистой установки».
- Не запускай случайные команды из интернета от имени root.
- Если обновление завершилось ошибкой, сохрани текст ошибки и не удаляй резервную копию. Сначала нужно выяснить, на каком этапе произошёл сбой.

## 9. Рабочая область и история результатов

Кнопка «Рабочая область» доступна на страницах панели. Возле поддерживаемых блоков результатов можно нажать «В рабочую область», чтобы закрепить нужный результат. После перехода на другую страницу закреплённые данные останутся доступны в панели рабочей области.

- Данные рабочей области сохраняются локально в хранилище браузера на этом компьютере.
- Они не синхронизируются с другими устройствами и не отправляются на сервер этой функцией.
- Не закрепляй пароли, токены, личные документы и другие секреты.
- Удалить отдельную запись можно кнопкой «Удалить», все записи — кнопкой «Очистить».
- История запусков в базе данных панели и локальная рабочая область браузера — разные функции.

## 10. GrabCam: учебный режим

GrabCam предназначен для демонстрации работы браузерных разрешений. Камера, геолокация и другие чувствительные возможности должны запрашиваться прозрачно и только в рамках явно обозначенной демонстрации с осознанным действием посетителя. Камера может отображаться локально в браузере; геолокация и выбранный файл — только в объёме, который посетитель понимает и разрешил.

Страница не должна скрытно фотографировать, записывать звук/экран, читать галерею без выбора пользователя или передавать данные в фоне. Открытие Instagram или другого стороннего сайта не позволяет локальной панели запрашивать разрешения от имени этого сайта. Для учебного опыта используется отдельная демонстрационная страница собственного приложения.

2. Скопируй точный текст ошибки.
3. Укажи, какую команду или кнопку нажал непосредственно перед ошибкой.
4. Если проблема появилась после обновления, сообщи, на каком проценте или этапе оно остановилось.
