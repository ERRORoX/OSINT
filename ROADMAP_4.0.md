# OSINT Panel 4.0 — план развития

## Принципы
- Сохранить текущую тёмную минималистичную визуальную систему и рабочие страницы; редизайн выполнять постепенно, без переписывания проекта с нуля.
- Не ломать существующие OSINT-инструменты и пользовательские данные.
- По умолчанию запускать панель только на localhost. Доступ из LAN — отдельный этап с аутентификацией.
- Только законные сценарии OSINT по открытым источникам. Не развивать сбор паролей, перебор учётных данных, скрытую съёмку, скрытый сбор файлов или данных формы.
- Все изменения — в отдельных ветках и через Pull Request; `main` не менять напрямую.
