# maigret — модуль OSINT Panel

## Назначение

Поиск публичных профилей по username через Maigret.

## Структура

- `manifest.json` — метаданные и зависимости.
- `backend/tool.py` — каноническая реализация интеграции.
- `tests/test_tool.py` — контрактные тесты без сетевых запросов.
- `OSINT_PANEL.md` — документация интеграции.
- `README.md` — оригинальная документация upstream-проекта, если она присутствует; не перезаписывается.

## Интеграция

Центральный runtime загружает класс из manifest. Старый импорт `backend/tools/tool_maigret.py` сохранён как совместимый адаптер.

Модуль предназначен для поиска публично доступных страниц и профилей. Он не выполняет аутентификацию, перебор паролей или обход механизмов доступа.

## Зависимости

См. `dependencies` в manifest. Upstream-проект и системные зависимости не устанавливаются автоматически.
