# Evidence Center

Локальное хранилище материалов расследования на SQLite.

## Возможности
- Сохранение названия, публичного HTTP(S)-URL, домена, источника, выдержки и заметок.
- Необязательное поле SHA-256 для контрольной суммы файла, полученной аналитиком локально.
- Просмотр, редактирование заметок и удаление.
- Данные остаются в локальной базе OSINT Panel.

Открыть: `/modules/evidence-center/`.

## Ограничения
Модуль не загружает страницы по URL и не скачивает файлы автоматически. Это предотвращает неожиданные сетевые обращения и SSRF. Сохраняйте только материалы, к которым у вас есть законный доступ. SHA-256 не вычисляется для URL; поле предназначено для хеша локального файла.
