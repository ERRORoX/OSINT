# Social Analyzer — модуль OSINT Panel

## Назначение

Поиск публичных профилей по username через upstream Social Analyzer.

## Структура

- `manifest.json` — метаданные и зависимости.
- `backend/tool.py` — каноническая backend-реализация.
- `tests/test_tool.py` — контрактные тесты без сетевых запросов.
- `OSINT_PANEL.md` — документация интеграции.
- `README.md` — upstream-документация, сохранена отдельно.

## Интеграция

Старый импорт `backend/tools/tool_social_analyzer.py` остаётся compatibility adapter. Основная реализация находится в этой папке.

Инструмент предназначен для обнаружения публично доступных профилей. Он не выполняет вход в аккаунты, подбор паролей или обход ограничений доступа.

Зависимости и upstream-исходники не устанавливаются автоматически.
