# Phone Number Intelligence

Пассивная проверка телефонных номеров в международном формате с помощью Python-библиотеки `phonenumbers`.

## Что показывает
- корректность и возможную валидность формата;
- формат E.164 и национальное представление;
- код страны и регион плана нумерации;
- тип номера;
- справочные сведения об исходном диапазоне оператора, если они есть в локальной базе.

## Ограничения конфиденциальности
Модуль не ищет владельца номера, адрес, геолокацию, социальные профили, утечки или иные персональные сведения. Сведения об операторе могут не учитывать перенос номера.

Зависимость: `phonenumbers` (устанавливается через Settings → Проверить инструменты).
