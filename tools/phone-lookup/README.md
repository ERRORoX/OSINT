# Phone Number Intelligence

Пассивный анализ международных телефонных номеров на базе локальной библиотеки `phonenumbers`.

## Данные в отчёте
- E.164, международный и национальный форматы;
- значащая часть национального номера и источник кода страны;
- код вызова, страна и регион плана нумерации;
- справочное географическое описание (если доступно);
- тип линии и машинный код типа номера;
- сведения об исходном операторском диапазоне;
- возможные часовые пояса;
- результат проверки длины и валидности по известному плану нумерации;
- пояснения о точности операторских и географических данных.

## Публичная репутация
- формируются ссылки на поиск публичных сообщений о спаме, мошенничестве и robocall в Google, Bing и DuckDuckGo;
- поиск запускается только после нажатия пользователем на ссылку;
- модуль не сканирует сайты автоматически и не собирает профили частных лиц.

## Функции интерфейса
- структурированная карточка результатов;
- быстрые подсказки кодов стран;
- копирование отчёта и экспорт JSON;
- история только в памяти текущей вкладки/сессии;
- сохранение технического телефонного узла в граф расследований.

## Ограничения и приватность
Не устанавливает личность владельца, адрес, GPS, текущее местоположение, активность SIM-карты, аккаунты мессенджеров или сведения из утечек. Валидность не означает, что номер активен. Оператор может отражать исходное распределение диапазона и не учитывать перенос номера. Географическое описание не является местоположением абонента. Поиск репутации показывает только публичные индексируемые сообщения и не подтверждает факт нарушения.

Зависимость: `phonenumbers` (устанавливается через Settings → Проверить инструменты).
