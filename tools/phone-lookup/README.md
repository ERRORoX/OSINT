# Phone Number Intelligence

Пассивный анализ международных телефонных номеров на базе локальной библиотеки `phonenumbers`.

## Технические данные
- E.164, международный и национальный форматы;
- значащая часть национального номера и источник кода страны;
- код вызова, страна и регион плана нумерации;
- справочное географическое описание (если доступно);
- тип линии и машинный код типа номера;
- сведения об исходном операторском диапазоне;
- возможные часовые пояса;
- результат проверки длины и валидности по известному плану нумерации.

## Автоматический поиск публичных упоминаний
После локального анализа модуль автоматически отправляет до четырёх поисковых запросов в Google Custom Search JSON API:
- общий поиск по точному номеру и цифровому формату;
- публичные страницы WhatsApp (wa.me / whatsapp.com);
- публичные страницы Telegram (t.me);
- публичные упоминания imo (imo.im / imoapp.com).

Для включения нужны серверные переменные окружения `GOOGLE_CSE_API_KEY` и `GOOGLE_CSE_CX`. Ключ нельзя помещать во frontend или коммитить в репозиторий. API должен быть доступен вашему Google-проекту. Google сообщает, что Custom Search JSON API закрыт для новых клиентов; существующим пользователям нужно планировать переход на поддерживаемую альтернативу. Если ключи не настроены, модуль честно покажет «не настроено», а не выдумает результаты.

**Важно:** эти запросы ищут только публично индексируемые веб-страницы. Они не подтверждают регистрацию номера в WhatsApp, Telegram или imo. Пустая выдача означает только отсутствие найденных публичных страниц по запросу. Модуль не входит в закрытые аккаунты, не импортирует контакты, не отправляет сообщения и не проверяет частные профили.

Ручной каталог ссылок остаётся доступен для дополнительных поисковых систем, соцсетей, репутационных баз и справочников.

Каталог источников сгруппирован по направлениям:
- поисковые системы: Google, Bing, DuckDuckGo, Brave Search и Yandex;
- публичные упоминания: Instagram, Facebook, VK, TikTok, X/Twitter, LinkedIn, Telegram, YouTube, Reddit и GitHub;
- репутация звонков: публичные страницы и отзывы Tellows, WhoCallsMe, 800notes, Should I Answer и общие жалобы;
- деловые следы: публичные карточки на картах, сайты организаций, каталоги и объявления;
- открытые обратные справочники: поиск публичных страниц Truecaller, Sync.me, NumLookup и других каталогов;
- телеком-справка: поиск оператора, диапазона, планов нумерации и материалов регуляторов.

Каталог использует поисковые запросы и публично индексируемые страницы. Наличие ссылки на сервис не означает, что сервис предоставляет бесплатный доступ, поддерживает конкретную страну или вернёт результат. Прямые API-провайдеры (например, Twilio Lookup) могут быть подключены отдельно при наличии ключа и согласии на возможные платные запросы.

Доступные поисковые источники:
- Google, Bing и DuckDuckGo — точное публичное упоминание номера;
- публично индексируемые страницы Instagram, Facebook, VK, TikTok, X/Twitter, LinkedIn, Telegram (t.me) и YouTube;
- публичные жалобы на спам, мошенничество и нежелательные звонки;
- публичные бизнес-упоминания и контактные страницы.

Автоматические результаты и ручные ссылки ведут только к публичным источникам. Модуль не устанавливает владельца номера и не делает вывод о наличии частного аккаунта. Результаты могут быть неполными, устаревшими или ошибочными. Отсутствие результатов не означает отсутствие аккаунта или публикаций.

## Функции интерфейса
- структурированная карточка результатов;
- группировка публичного поиска по категориям;
- копирование отчёта и экспорт JSON;
- история только в памяти текущей вкладки/сессии;
- сохранение технического телефонного узла в граф расследований.

## Ограничения и приватность
Не устанавливает личность владельца, адрес, GPS, текущее местоположение, активность SIM-карты, скрытые аккаунты или сведения из утечек. Не пытается определить, зарегистрирован ли частный номер в конкретном сервисе. Валидность не означает, что номер активен. Оператор может отражать исходное распределение диапазона и не учитывать перенос номера. Географическое описание не является местоположением абонента.

Зависимость: `phonenumbers` (устанавливается через Settings → Проверить инструменты).
