# AI Agent

Интерфейс AI-агента OSINT Panel. Frontend находится в `frontend/`; общие API, настройки провайдера и оркестрация остаются в ядре приложения.

Канонический адрес: `/modules/ai-agent/`. Старый адрес `/p/ai-agent/` перенаправляет на него.

Не храните API-ключи в каталоге модуля или в manifest.
