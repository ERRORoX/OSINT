# Investigation Workspace

Единое рабочее пространство OSINT Panel.

## Возможности
- Graph 2.0: интерактивное перемещение узлов, масштабирование, панорамирование, фильтрация типов, авторасстановка, просмотр происхождения источников, поиск кратчайшего пути.
- Unified Search: классификация ФИО, телефона, username, IP, домена и email с переходом в профильные модули; ФИО ищется только по публично индексируемым источникам.
- Investigation Manager: создание, переключение, переименование и удаление расследований; заметки привязаны к расследованию.

## Маршрут
`/modules/investigation-workspace/`

## API
Используются существующие API `/api/graph`, `/api/graph/merge`, `/api/investigations`, `/api/investigations/notes`, `/api/public-person-search` и `/api/evidence`.

Совпадение имени или публичное упоминание не доказывает личность. Модуль не обращается к приватным аккаунтам, закрытым телефонным книгам или слитым базам.
