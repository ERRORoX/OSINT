# IP / RDAP

Пассивный инструмент для получения регистрационных сведений о публичном IPv4/IPv6 адресе через RDAP.

## Структура

- `manifest.json` — декларативное описание модуля.
- `frontend/index.html` и `frontend/page.js` — страница и клиентская логика.
- `backend/tool.py` — реализация инструмента.
- `README.md` — документация модуля.

## Запуск в OSINT Panel

Канонический адрес: `/modules/ip-rdap/`.

Совместимый старый адрес: `/p/ip-rdap/` — перенаправляет на каноническую страницу.

Существующий API запуска сохраняется: `POST /api/tools/ip-rdap/run`.

## Поведение и ограничения

- Принимаются только корректные публичные IPv4/IPv6 адреса.
- Приватные, loopback, link-local и иные непубличные адреса отклоняются.
- Инструмент выполняет запрос к RDAP-сервису, не сканирует IP и не проверяет открытые порты.
- Результат зависит от полноты и доступности RDAP-источника.
- Сетевые запросы ограничены тайм-аутом и размером ответа.

## Архитектурные правила

Модуль не должен импортировать внутренние файлы других инструментов. Общий контракт `ToolBase` пока предоставляется backend-ядром через compatibility adapter. Новые общие возможности следует добавлять в core, а не копировать сюда.

Пользовательские данные и настройки не должны храниться внутри каталога исходного кода.
