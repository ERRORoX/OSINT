# Person Intelligence

Бесплатная страница для поиска по ФИО в публичных источниках.

- Локальная генерация вариантов ФИО и транслитерация кириллицы в латиницу с поддержкой таджикских букв.
- Поисковые ссылки Google, Bing, DuckDuckGo, Brave Search и Yandex.
- Публичные страницы VK, Одноклассников, LinkedIn, Facebook, Instagram, TikTok, YouTube, Telegram и GitHub.
- Поиск по публичным документам, организациям, новостям и академическим материалам.
- Maigret и Sherlock уже находятся в проекте; они ищут по известному username, не по ФИО.
- Дополнительный автоматический режим использует существующий /api/public-person-search и серверный Brave Search API из Phone Intelligence. Без ключа ручной поиск работает.

Используются только публичные поисковые индексы и открытые страницы. Закрытые аккаунты, приватные контакты и сырые дампы утечек не проверяются. Совпадение по ФИО не доказывает принадлежность профиля конкретному человеку.
