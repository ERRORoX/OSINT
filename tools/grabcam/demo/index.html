Учебная демонстрация GrabCam

Эта страница предназначена для показа принципов браузерных разрешений в тестовой лаборатории.

Важно: камера и геолокация не включаются автоматически. Доступ запрашивается только после нажатия соответствующей кнопки. Данные не отправляются на сервер и не сохраняются.

Проверка разрешения камеры

Нажмите кнопку, чтобы браузер показал стандартный запрос доступа. Изображение отображается только в этом окне.

Проверка разрешения геолокации

Запрос координат выполняется отдельно и только после нажатия.
