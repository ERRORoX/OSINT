# Photo Workspace

Единая интерфейсная рабочая область для анализа изображений.

## Состав

- `frontend/index.html` — страница workspace.
- `frontend/css/photo.css` — локальные стили.
- `frontend/js/photo.js` — клиентская логика.
- `manifest.json` — метаданные и зависимости.

Связанные backend-функции остаются отдельными tool-модулями и вызываются через стабильные API панели. В частности, `photo-search` отвечает за базовый анализ файла и метаданные.

## Адреса

- Канонический: `/modules/photo-workspace/`.
- Совместимый старый: `/photo/`.

## Безопасность

Изображение загружается пользователем явным действием. Не добавляйте автоматическое извлечение файлов из галереи или фоновую передачу изображений.
