# dnsx — модуль OSINT Panel

## Назначение

DNS-запросы A, AAAA и CNAME с использованием ProjectDiscovery dnsx.

## Структура

- `manifest.json` — метаданные модуля.
- `backend/tool.py` — каноническая реализация интеграции.
- `tests/test_tool.py` — контрактные тесты.
- `OSINT_PANEL.md` — документация интеграции OSINT Panel.
- `README.md` — оригинальная документация upstream-проекта, сохранена без изменений.

## Интеграция

Центральный реестр сохраняет прежний импорт через `backend/tools/tool_dnsx.py`. Этот файл теперь только compatibility adapter. Новые изменения реализации выполняются в `backend/tool.py`.

Бинарник ищется сначала в каталоге `tools/dnsx/`, затем в системном PATH. Автоматическая загрузка или установка бинарника не выполняется.

Модуль вызывается через API панели и используется Domain Workspace.
