# theharvester — модуль OSINT Panel

## Назначение

Интеграция с theHarvester для сбора открытых email-адресов, поддоменов и связанных данных по домену.

## Структура

- `manifest.json` — метаданные, версия, статус и зависимости.
- `backend/tool.py` — каноническая backend-реализация.
- `tests/test_tool.py` — изолированные проверки контракта и валидации.
- `OSINT_PANEL.md` — документация интеграции.

## Интеграция

Центральный реестр сохраняет старый импорт через `backend/tools/tool_theharvester.py`. Это compatibility adapter; основная реализация находится в этой папке.

API-ключи читаются из существующих настроек/переменных окружения. Не сохраняйте ключи в manifest, исходниках или репозитории.

## Зависимости

См. раздел `dependencies` в manifest. Установка внешних компонентов выполняется общим dependency workflow проекта, а не автоматически при чтении manifest.
