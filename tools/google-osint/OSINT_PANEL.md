# Google OSINT — модуль OSINT Panel

## Назначение

Комбинированная проверка email: публичные следы регистрации через Holehe и проверка по доступным источникам утечек через h8mail.

## Структура

- `manifest.json` — метаданные и зависимости.
- `backend/tool.py` — orchestration и публичный ToolBase-контракт.
- `backend/holehe.py` — локальная интеграция Holehe.
- `backend/h8mail.py` — локальная интеграция h8mail.
- `tests/test_tool.py` — безопасные тесты без внешних запросов.
- `OSINT_PANEL.md` — документация интеграции.

## Безопасность

- Принимается только email, переданный пользователем.
- Никакие письма не отправляются и в аккаунты не выполняется вход.
- API-ключи берутся из существующего хранилища настроек/окружения и не включаются в manifest.
- Внешние проверки выполняются только после явного запуска инструмента.

## Совместимость

Старый `backend/tools/tool_google_osint.py` остаётся compatibility adapter. Новые изменения выполняются в этой папке.
